# خطة تنفيذ تقييد هدية الموقع بحساب المستخدم المسجل

## المشكلة السابقة
عند تسجيل الخروج من الموقع (`Déconnexion`) كانت حالة فتح الدورة الهدية المجانية تحفظ محلياً في مفتاح عام `gc58_gift_unlocked` بدون ربطها بحساب المستخدم، مما كان يجعلها تظهر مفتوحة لأي زائر حتى بعد الخروج.

## التعديلات المنجزة

1. **عزل حالة الفتح لكل حساب مستخدم (`User Scoped Storage`):**
   - تم ربط مفتاح الفتح برقم المستخدم الفريد: `gc58_gift_unlocked_${user.uid}`.
   - في حال كان المستخدم غير مسجل دخول (`!user` أو بعد الضغط على خروج)، تكون حالة `isUnlocked` دائماً مقفلة تلقائياً (`false`).

2. **قفل الواجهات الخارجية عند تسجيل الخروج:**
   - زر "هدية الموقع 🎁" في شريط التنقل (`Navbar`) يطلب تسجيل الدخول فوراً إذا لم يكن المستخدم مسجلاً.
   - قسم الهدية في الصفحة الرئيسية (`GiftCourseSection`) يعرض زر "دخول الحساب لفتح هدية الموقع" ويفتح نافذة تسجيل الدخول عند النقر، مع منع فتح الفيديوهات من الخارج.
   - نافذة العرض والمشغل (`GiftCourseModal`) تعرض شاشة "يجب تسجيل الدخول إلى حسابك أولاً" بمجرد الخروج.

3. **إضافة قسم مخصص للدورة الهدية داخل لوحة تحكم الطالب (`StudentDashboard`):**
   - قسم مخصص وبارز داخل فضاء الطالب يعرض حالة الدورة (مفتوحة ومفعلة بحسابك 🔓 / مشفرة بكود سري 🔒).
   - إمكانية إدخال الكود السري لفك التشفير وتثبيت الفتح بحساب الطالب مدى الحياة.
   - زر مباشر للمشاهدة ورابط طلب الكود عبر الواتساب.
